# Burned World – Inferno (Fabric 1.21.4)

Experimental Minecraft Java Fabric mod inspired by a burned Nether-like world.

**Status:** v0.3.0-beta1 is experimental and has not been tested in a running Minecraft client. Make a backup and test in a new world.

Requires Minecraft Java 1.21.4, Fabric Loader, and matching Fabric API.

The JAR is a custom beta, not the original Wisp modpack.
